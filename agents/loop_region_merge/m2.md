# M2 实现与验收记录

已实现区域内读写全局状态的通用合并；未加入任何具体寄存器特例。修改仅位于本工作树，没有执行 commit、branch 或 stash。

## 配置与访问规则

- `ExecutionLimits::region_global_state` 默认关闭，构造方法为 `with_region_global_state`。原 `with_path_merging` 单独使用时不改变旧行为；isarch 经原 `solve_execution_limits → with_config → with_path_merging` 路径解析策略后随 path merging 打开新选项。
- 寄存器读先区分当前臂是否已写；包含已合并的内层写。内部读不记录足迹、不发布 `ReadReg`；前态读按完整 `(寄存器, accessor)` 去重。全局 let 沿用无寄存器事件的既有读取机制，惰性初值仍由 `initial_lets.entry` 共享。
- 动态日志与静态函数摘要均允许普通全局写；寄存器写序只保留首次写入。读取足迹按两臂偏序做拓扑合并，共同足迹的条件取 OR，单臂足迹保留原条件记录。
- 复用既有 `merge_states/merge_val` 合并最终值，并按既有整寄存器事件路径发布 `WriteReg`。`WRITE_REGISTER_FROM_VECTOR` 的实际写回经过 `record_write`，已通用放开并有执行测试。
- 保持其他写效应、内存写、relaxed 与历史写入寄存器的拒绝。新选项开启时地址写在实际写入前拒绝，被调函数地址写仍可由静态摘要提前拒绝。
- 未修改 `RegionMergeRecord`、FastFacts、DAG 或路径缓存格式，没有升级缓存 schema。

## 冒烟

仓库约定的 `make solve-MRET` 使用刚编译的 release（二进制不重建），32 线程，外部 60 秒、路径 1 分钟，无 execution limit 或 workaround。4.73 秒退出，产出 3 条用例后因 `zext_decode` 译码回环返回 `Poison` 失败；没有 panic。见 `validation-m2/make-mret.log`、工作树 `output/log/MRET.log` 和 `output/process/MRET-8.json`。该运行错误未扩展到 M2 之外处理。

FVFTYPE 单次冒烟的命令、日志及进程监督结果保存在 `smoke-m2/`；32 线程，`--timeout 5m`，外部时限 280 秒，未使用任何 `--path-cache-*` 参数。实际 281.31 秒退出（返回码 124，触达外部时限）；无 panic，日志中 `callee_state_write` 为 0。最后快照：合并尝试 45、成功 35、失败 7（`has_back_edge=1`、`incompatible_state=5`、`retry_operand=1`），尚有推演未结束，因此快照计数不要求相加等于尝试数。该短跑没有完成整个 clause，不作长时通过结论。见 `smoke-m2/summary.json`。

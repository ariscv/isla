快照权重是硬超时前的观测次数，不代表独立静态位置数或动态合并成功数。预检逐节点复用 `instruction_effect` 和 `function_effect_summaries`，表中细分采用首个拒绝证据，每个入口权重只计一次；JSON 还保留区域内全部静态拒绝证据、直接被调函数和写入位置。静态可通过不保证运行时状态兼容。M1 之后区域死臂不经过普通执行的 `assertion_filtered_paths` 计数，接受设计稿约定的统计口径变化。

## 复现

在本工作树根目录执行；所有输出与临时文件留在本工作树。

```sh
python3 agents/loop_region_merge/measure.py extract
mkdir -p agents/loop_region_merge/tmp
TMPDIR="$PWD/agents/loop_region_merge/tmp" \
ISLA_REGIONS_IR=/data1/baiyifan/workplace/isla-runner/.worktree/pathmerge-all-20261110/isla/rv64d.ir \
ISLA_M0_INPUT="$PWD/agents/loop_region_merge/m0-baseline.json" \
ISLA_M0_OUTPUT="$PWD/agents/loop_region_merge/m0.json" \
cargo test -p isla-lib regions_loop_merge_real_ir_measurement -- --ignored --nocapture
python3 agents/loop_region_merge/measure.py report
```

首次只测现状时，输入改为 `snapshots.json`、输出改为 `m0-baseline.json`，并设置 `ISLA_M0_BASELINE_ONLY=1`。

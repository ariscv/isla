# 模型异常终态过滤

目标：按 TOML / CLI 指定的异常构造子集合，在终态收集边界排除 Sail 异常；默认集合为空。现场执行及旧缓存读回使用同一匹配逻辑，summary 保留总数与构造子＋消息分项。

范围：仅本工作树；配置解析、isarch collector、样本会话、缓存元数据、文档与定向测试。不改 Sail 或 isla-lib 合并／求解逻辑，不提交、合并或 push。

步骤：先增加最小 IR 与配置失败测试，再实现配置／CLI、现场及缓存过滤，运行 exec / samples / path_cache 定向回归和 cargo fmt，限定审查本轮增量，最后重读共享 result.md 并追加章节。

验证：最小 IR 含正常、内部异常、保留行为、未实现异常、AssertionFailure；检查默认关闭、配置集合精确匹配、消息分项、缓存旧格式及重载。真实 PMP=2 缓存为可选，只在输入／scheduler 具备时做 30 秒短验证，不扩大实验。

选择：CLI 重复传构造子名，出现 CLI 参数时整体覆盖 TOML 集合；空集合保留默认行为。缓存逐终态按构造子重判，不使用二进制哈希作有效性门槛。

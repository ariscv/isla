# 运行值数据模型

## 符号长度位向量

Isla 在执行过程中可以用 `Val::SymBits` 保存位宽由符号表达式决定的位向量。`data` 是宽度为 `cap` 的 SMT 位向量，`len` 是表示实际位宽的 128 位 SMT 符号。只有 `data` 的最低 `len` 位属于该值。`cap` 来自可证明的结构上界。Sail 的变长位向量类型与 IR 表示沿用原有定义。

例如，页表层级的两位输入让 `sail_ones(level * 9)` 的位宽可为 0、9、18 或 27。执行器可以用 27 位的数据和符号长度保留四种可能，再把掩码零扩展到 45 位。需要固定容量但无法确定可表示上界时，执行器沿长度约束拆分。要求等宽的位运算拒绝实际位宽不同的操作数。

抽象事件、执行迹和路径缓存使用定宽值。当出口只有一种可行位宽时，执行器保留该宽度的符号数据。有多种可行位宽时，执行器按互补守卫拆分并保留各自的数据。样本使用最终求解模型取得实际位宽和数据。路径缓存继续使用版本 7。

旧配置文件中的 `execution_limits.path_merge.sym_bits` 已删除，配置解析会报告未知字段。
